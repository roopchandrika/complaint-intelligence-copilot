# Complaint Intelligence Copilot
**Scenario.** I am a Forward Deployed Engineer embedded with the customer
support team of a fictional retail bank. Support agents spend too long
researching escalated complaints across a legacy case system, complaint
exports, and regulatory guidance. This project builds a secured RAG + agent
copilot that answers their questions with citations.
**Client data.** Public CFPB Consumer Complaint Database (stand-in for the
bank's complaint export) plus public CFPB regulatory PDFs.
**Status.** Phase 1 – data engineering.
